# Aurora Mini App

Telegram Mini App для сделок: аккаунты, подарки, NFT Telegram, Stars.

## Сайт

После включения GitHub Pages:

**https://afiomacomplate.github.io/ggsell/**

## Как включить GitHub Pages

1. Репозиторий → **Settings** → **Pages**
2. Source: **GitHub Actions**
3. Дождись зелёного workflow **Deploy GitHub Pages**

## Как подключить в Telegram

1. [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй токен
2. `/newapp` → выбери бота → URL Mini App:

```
https://afiomacomplate.github.io/ggsell/
```

3. Короткое имя, например `aurora`
4. Ссылка на приложение: `https://t.me/ТВОЙ_БОТ/aurora`

## Важно

Пополнение баланса — демо. Лоты хранятся в браузере пользователя.
Поддержка в Mini App работает локально; ответы через Telegram-бота нужны на сервере с HTTPS webhook.
